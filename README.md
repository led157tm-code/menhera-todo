# メンヘラ彼女ToDoする？

## 概要
LINE風の画面で、メンヘラの女の子とやり取りしながらタスク管理ができるToDoアプリ。

## 制作のきっかけ
既存のToDoアプリに魅力を感じなかった。
そこで、女の子がタスクを気にかけてくれたり、達成できた時に反応してくれたりしたら嬉しいなと考えて制作。

## 実装した機能
- LINE風チャット画面
- タスク管理
- 期限による女の子の状態変化4種
- 状態に合わせた画像・BGM・セリフ変化
- 疑似的な通知機能

## 制作について
私はプログラミング経験がほとんどありませんでしたが、自分の考えた体験をどうしても実現したいと思い、生成AI（ChatGPT）を活用しました。

AIにコード生成や修正を相談しながら、出力されたコードのデバッグを行い、必要な部分のみを変更するという流れで制作。

メンヘラの女の子とのコミュニケーションを組み合わせることで、私が「課題を達成したい！」と思えるように考えた。

メンヘラなので期限によって女の子の機嫌が変化するのが最大の特徴であるため、時間経過が直感的に伝わるようにしました。

また、女の子の機嫌の変化をセリフ、画像、BGM、通知、UIで感じれるようにし、臨場感を得られるようにしました。

## 制作で意識したこと

タスク管理をメンヘラの女の子とのやり取りによって継続したくなるようにした。
